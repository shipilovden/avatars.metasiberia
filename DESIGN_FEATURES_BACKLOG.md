# Design Features Backlog

Рабочий список только для незавершенных задач.

Правило файла:

- после выполнения пункт удаляется из списка
- сюда попадают только реальные следующие шаги
- не держим здесь то, что уже есть в редакторе

## Что относится именно к дизайну

- Управление паттерном внутри слоя
  `scale`, `offset`, `rotation`, `repeat`, `mirror repeat`.

- Layer Styles
  `stroke`, `shadow`, `outer glow`, `gradient overlay`.

- Style Presets
  Готовые наборы настроек для быстрого старта: `sport`, `cyber`, `vintage`, `grunge`, `luxury`.

- Генератор фактуры
  `grain`, `distress`, `faded print`, тканевый шум.

- Автопалитра
  Выделение основных цветов из загруженной картинки или паттерна.

- Material-aware preview
  Один и тот же дизайн по-разному выглядит на ткани, коже, неоне, металле.

- Seam-aware placement
  Более умное размещение принта с учетом швов и формы одежды.

## Что относится к общим механикам редактора

- Drag-and-drop перестановка слоев
  Сейчас логичнее перейти от кнопок вверх/вниз к прямому перетаскиванию.

- Визуальные guides
  Линии центра, края, симметрии, безопасные зоны.

- Группы слоев
  Папки, групповое скрытие, групповая прозрачность.

- Режим симметрии
  Зеркальное редактирование для левой и правой стороны.

- Warp / Distort
  Легкая деформация слоя по форме одежды.

## С чего начинаем

Первым берем `Управление паттерном внутри слоя`.

Почему именно с них:

- это действительно дизайн-фича, а не общая инфраструктура
- эффект сразу виден в интерфейсе
- хорошо ложится на текущий canvas-based рендер
- логично продолжает уже добавленные `Blend Modes`

## Что уже не держим в этом списке

Ниже вещи, которые уже в редакторе есть хотя бы в рабочем базовом виде, поэтому в backlog их не дублируем:

- слои
- видимость слоя
- opacity
- lock
- solo
- undo / redo
- transform
- crop
- mask
- snap
