# Design Features Backlog

Рабочий список только для незавершенных задач.

Правило файла:

- после выполнения пункт удаляется из списка
- сюда попадают только реальные следующие шаги
- не держим здесь то, что уже есть в редакторе

## Что относится именно к дизайну

- Стили слоя
  Внешнее свечение, наложение градиента, внутренняя тень.

- Автопалитра
  Выделение основных цветов из загруженной картинки или паттерна.

- Предпросмотр с учетом материала
  Один и тот же дизайн по-разному выглядит на ткани, коже, неоне, металле.

- Умное размещение по швам
  Более аккуратная посадка принта с учетом швов и формы одежды.

## Что относится к общим механикам редактора

- Drag-and-drop перестановка слоев
  Перетаскивание слоев мышкой вместо кнопок вверх/вниз.

- Визуальные направляющие
  Линии центра, края, симметрии и безопасные зоны.

- Группы слоев
  Папки, групповое скрытие и групповая прозрачность.

- Режим симметрии
  Зеркальное редактирование для левой и правой стороны.

- Деформация слоя
  Легкая подгонка формы дизайна под одежду.

## Что берем следующим

Сейчас самый сильный следующий шаг: `Внешнее свечение`.

Почему именно оно:

- сразу делает дизайн более акцентным и заметным
- отлично работает вместе с уже сделанными тенью, обводкой и паттернами
- особенно хорошо подходит для неона, кибер-стиля, логотипов и эмблем

После него логичный порядок такой:

1. Внешнее свечение
2. Наложение градиента
3. Внутренняя тень

## Макет Photoshop-like UV-окна

Эти фичи не выносим в отдельный экран. Все живет внутри текущего плавающего UV-окна.

Базовая схема окна:

```text
+--------------------------------------------------------------+
| Header: layers / mode / file / undo / redo / close           |
+----------------------+---------------------------------------+
| Layers               | UV canvas / preview                   |
|                      |                                       |
| [layer item]         | transform handles                     |
| [mask item]          | guides / seams / safe area            |
| [fx item]            | warp mesh / crop / brush overlay      |
| [adjustment item]    |                                       |
+----------------------+---------------------------------------+
| Inspector tabs: Layer | Mask | Effects | Print               |
+--------------------------------------------------------------+
| Controls for the active tab                                  |
+--------------------------------------------------------------+
```

Что именно добавляем в текущее окно:

- слева остается список слоев, но у каждого слоя появляются `mask`, `fx`, `duplicate`, `hide`
- по центру остается UV-canvas, но он умеет показывать `warp grid`, `seams`, `safe area`, `mirror`, `guides`
- снизу живет один inspector с вкладками `Слой`, `Маска`, `Эффекты`, `Печать`
- новые инструменты не выносим в новую панель, а добавляем в текущий ряд с `Трансформ`, `Обрезка`, `Кисть`, `Ластик`

### Вкладка `Слой`

- opacity
- blend mode
- position
- scale X / scale Y
- rotation
- warp
- snap to center / seams

### Вкладка `Маска`

- добавить маску
- переключение `рисовать маску / рисовать слой`
- brush size
- softness
- invert mask
- show mask overlay
- unlink mask from layer transform

### Вкладка `Эффекты`

- stroke
- outer glow
- inner shadow
- drop shadow
- bevel / emboss lite
- pattern overlay
- gradient overlay

### Вкладка `Печать`

- type: `Обычная`, `Шелкография`, `Резина`, `Вышивка`, `Puff`
- fabric response
- ink density
- height / depth
- roughness
- edge wear
- seam fade

## Этапы внедрения без перегруза

1. Общий inspector с вкладками внутри текущего UV-окна.
2. Layer mask с mask brush и mask overlay.
3. Effects tab со stroke, glow и shadow.
4. Warp / mesh warp для принтов и design-layer.
5. Print modes с реакцией на материал.

## Что брать прямо сейчас

Если делать максимум пользы при минимуме хаоса, то порядок такой:

1. `Layer mask`
2. `Effects tab`
3. `Warp`

Это даст ощущение настоящего mini-Photoshop внутри уже существующего UV-редактора без перелома всего UX.
