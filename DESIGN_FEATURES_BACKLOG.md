# Design Features Backlog

Рабочий список только для незавершенных задач.

Правило файла:

- после выполнения пункт удаляется из списка
- сюда попадают только реальные следующие шаги
- не держим здесь то, что уже есть в редакторе

## Что относится именно к дизайну

- Стили слоя
  Тень, внешнее свечение, наложение градиента, внутренняя тень, обводка текста.

- Готовые стили
  Наборы настроек для быстрого старта: спортивный, кибер, винтажный, гранж, люкс.

- Генератор фактуры
  Зерно, потертость, выцветшая печать, тканевый шум.

- Автопалитра
  Выделение основных цветов из загруженной картинки или паттерна.

- Предпросмотр с учетом материала
  Один и тот же дизайн по-разному выглядит на ткани, коже, неоне, металле.

- Умное размещение по швам
  Более аккуратная посадка принта с учетом швов и формы одежды.

## Что относится к общим механикам редактора

- Drag-and-drop перестановка слоев
  Перетаскивание слоев мышкой вместо кнопок вверх/вниз.

- Визуальные направляющие
  Линии центра, края, симметрии и безопасные зоны.

- Группы слоев
  Папки, групповое скрытие и групповая прозрачность.

- Режим симметрии
  Зеркальное редактирование для левой и правой стороны.

- Деформация слоя
  Легкая подгонка формы дизайна под одежду.

## Что берем следующим

Сейчас самый сильный следующий шаг: `Тень`.

Почему именно она:

- сразу добавляет объем и глубину
- хорошо работает вместе с уже сделанными паттернами и обводкой
- быстро усиливает эффект стикеров, логотипов и эмблем

После нее логичный порядок такой:

1. Тень
2. Внешнее свечение
3. Наложение градиента
4. Внутренняя тень
5. Обводка текста

## Что уже не держим в этом списке

Ниже вещи, которые уже есть в редакторе хотя бы в рабочем базовом виде, поэтому в backlog их не дублируем:

- слои
- видимость слоя
- opacity
- lock
- solo
- undo / redo
- transform
- crop
- mask
- snap
- управление паттерном внутри слоя
- обводка фигур
- своя текстура внутри фигуры
